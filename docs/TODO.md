## 项目整体进展

### 已完成能力
- 用户注册/登录/Profile（JWT鉴权）
- 项目CRUD、成员管理（OWNER/EDITOR/VIEWER）
- 文件树系统（增删改查、文件夹层级）
- RabbitMQ异步文件操作（project-service ↔ file-service）
- IDE风格前端：文件树 + Monaco Editor，Ctrl+S保存
- Docker容器化（MySQL/Redis/RabbitMQ）

### 核心技术栈
- 后端：Spring Boot 3.x + Java 17，5个微服务（端口 8080-8084）
- 前端：Vue 3 + TypeScript + Monaco Editor + Element Plus
- 数据库：MySQL + Redis + MongoDB
- 消息队列：RabbitMQ
